# Data Source and Provenance

## Dataset

Default of Credit Card Clients

## Source

UCI Machine Learning Repository

## Dataset ID

350

## DOI

10.24432/C55S3H

## Original Study

Yeh, I-Cheng and Lien, Che-hui (2009), "The comparisons of data mining techniques for the predictive accuracy of probability of default of credit card clients", Expert Systems with Applications.

## Analytical Task

Binary classification: predict whether a credit-card client will default.

## Dataset Scale

- 30,000 observations
- 23 predictive features
- one binary response variable

## Domain

Credit risk / financial services.

## Licensing

Creative Commons Attribution 4.0 International (CC BY 4.0).

## Reproducibility

The project retrieves the dataset programmatically through the `ucimlrepo` Python package. Raw CSV and Parquet versions are generated locally together with SHA-256 checksums and retrieval metadata.

Raw data files are excluded from GitHub. The acquisition code and provenance documentation are committed instead.
